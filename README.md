# 丁福保《佛學大辭典》→ `dfb.adb`

本倉是**建庫端**；抓取端在 `../fodict`（BAUS 原始抓取與三張校勘表），成品發布在母區 `../adb-converter` 的官網工具鏈。
本檔是完整的工序記錄：每一步的命令、實測數、判準、以及走過又被推翻的路。數字皆由腳本重跑可得，不是憑記憶寫的材料稿。

## 一、資料與授權

| 項目 | 內容 |
|---|---|
| 書 | 丁福保《佛學大辭典》（1922 年初版），31,585 條 |
| 授權 | **CC0 1.0 Universal（公有領域貢獻）**。理由：作者 1952 年逝世，已逾 50 年，原書著作財產權消滅；本庫的轉寫／正規化不另創著作 |

## 三、工序（順序不可調）

**抓取 → 建 adb → backlink → 經名核對 → 閘門 → 重打包 → 驗收 → 對賬**

拿錯代的行檔比對是本專案最貴的一課：曾用「去掉 `<例>` 行之前」的 matches（140,314 行序）去比新版（108,730 行），79.5% 被誤判成「對不回」，連同先前那份「19.6% 不符」一起作廢。

### 1. 建庫：`src/dfb2adb.ts`

```
bun run src/dfb2adb.ts            # 產 out/dfb-lines.txt 與 out/dfb.adb
bun run src/dfb2adb.ts --dry      # 只出文字的中間檔，不建庫
```

輸出形如：

```xml
<檔 n="dfb.xml">
<集 scheme="術語,名數,雜語,…（87 種依頻次）">佛學大辭典</集>
<樹 s="$詞" t="詞">佛學大辭典</樹>
</檔>
<檔 n="dfb1.xml">
<詞 id="1" t="雜語">一一</詞>
猶言逐一也。首楞嚴經曰：「現一一形，誦一一咒。」
```

四個轉化，每個都有實測數與留檔：

| 轉化 | 做法 | 實測 |
|---|---|---|
| CBDIA 轉寫 → Unicode | 依 **(記號, 基字)** 二元鍵查 `data/translit-cbdia-map.tsv`（`%` 在母音是長音、在子音是點上；`^` 在 `n` 是波浪） | 轉 6,890／6,936（99.34%），留 46 處不硬湊（`out/translit-*.tsv`） |
| 組字式缺字 → 正字 | `data/gaiji-bracket-map.tsv` 165 種 | 轉 919／964，留 45 |
| 87 種體例標籤 → 詞頭屬性 | `（術語）` 剝掉改成 `<詞 t="術語">`，閱讀端在詞頭前染色塊（`patch/`） | 覆蓋 31,584 條（無體例 2 條） |
| `(參見：X)` → `<聯 n="X">` | **只有 X 確是詞頭才成鏈**，死鏈留原文 | 成鏈 5,891、死鏈留原文 400 |
| 義項序號前分段 | 在「（一）（二）…」前插 **不帶 n 的 `<段/>`**（帶 n 是巴利藏的跨庫對齊鍵，會憑空長出點不動的 `¶` 晶片） | 插入 137 處／66 行；判準見 `out/seg-review.md` |

`<段/>` 的判準：序號前有句讀邊界 `[。．：；！？）」』】]`、且其後第一個可見字不是 `[。，、；：）]`。這道規則擋掉 273「一相法門」那種「…是即名為一相法門（一）。」的尾注用法——切了會截斷句子。**改動是純增量**：新文字的中間檔去掉 137 個 `<段/>` 後與上一版 **sha256 相同**（`0c68ff9f9e76…`），行數 108,730 不變。

### 2. 字元級經文鏈：母區 `ts/tools/backlink.ts`

```
cd ../adb-converter
bun ts/tools/backlink.ts --src ../dfbdict/out/dfb.adb \
    --out ../dfbdict/out/dfb-taisho.adb --slug dfb-v3 \
    --cues "曰：,云：,言：,說：,：「,道："
```

**`--cues` 務必帶**：工具的預設提示語只有五條，忘帶會只抽出 1,845 筆引文（應為 27,024），產出一顆只有 1,176 錨點的庫。
本庫引文 27,024 筆 → 大正候選錨點 14,235。`match.line` 是 **0 起算**的行下標。

### 3. 經名核對：`src/check-titles.ts`

「先用引文查出候選頁，再用經名核對它挑的本經對不對」——這是作者定的方法。三件事：

- **回指繼承**：`同／又／前／次／本／此／是` 起頭且剝掉後只剩裸體裁字（經論疏記偈品中上下注釋…），或整個題面就是光杆一字（「偈曰」「中曰」「註云」）。先行詞**先近後遠**：①本條正文裡、這段引文之前最近出現的經名（作者舉例「佛說阿彌陀經之異名。…同經曰：『汝等眾生…』」正是這種）②退回首條已確定的經名。實測判為回指 929 條 → 正文回溯 764、順序繼承 149、前無經名 16。
- **簡稱展開**：`data/title-map.tsv`（用兩庫自己的 `書` 表反推）。比對用**連字子序列**——`法華經` 不是 `妙法蓮華經` 的連續子串。比對一律要求**兩字以上**：單字「經」是任何書名的子序列，靠它配對是假通過（曾把 273 那類判成「一致」）。
- **品名剝離**：`法華經譬喻品 → 法華經`。尾巴必須真的有卷品章節才剝；舊式尾巴選填，會把「法華經玄義」「四分律刪繁補闕行事鈔」「四十二章經」攔腰截斷（全庫多鋦開 2,140 條書名）。

書名底表 `data/corpus-titles.tsv`（大正 3,000＋卍續 1,236，去重 **4,108 部**，`src/dump-corpus-titles.ts` 產）；異寫 `data/title-variant.tsv`（4 對：一↔壹、秘↔祕、咒↔呪、倫↔論）；注家／省稱 `data/title-master.tsv`（22 條，含**玄應音義與慧琳音義在大正同名**的衝突註記）。三張表由 `src/verify-title-tables.ts` 校驗：**目標查不到即非零退出**，防手寫表隨語料重打包而腐化。

### 4. 閘門與重打包

```
bun run src/check-titles.ts --slug dfb-v3      # → out/gate-keep-dfb-v3.json
bun run src/apply-gate.ts   dfb-v3             # 把保留集落到 backlink 的 matches 上
cd ../adb-converter && bun ts/tools/backlink.ts --slug dfb-v3 --reuse \
    --src ../dfbdict/out/dfb.adb --out ../dfbdict/out/dfb-linked.adb \
    --cues "曰：,云：,言：,說：,：「,道："        # 用產品自己的套用＋打包，不另寫一套
```

閘門依作者裁定剔兩類：**經名不符**、**候選 > 100**（短通用引文，位置靠猜）。判定分佈（14,235 候選）：一致 5,895｜簡稱/異寫 2,292｜不符 2,824｜無題面記錄 2,221｜部分相符 970｜題名過短 26｜回指無先行詞 6｜未解 1 → **保留 11,077 → 發射 10,577 個錨點**。

### 5. 驗收：`src/verify-dfb.ts`

```
bun run src/verify-dfb.ts D:/accelon3/dfb.adb        # 對「實際部署那一顆」跑
```

六節，**每一節都有「樣本數為零即失敗」的硬柵欄**（曾拿 `db.text()` 數 `<詞>` 得 0 卻報通過）：

- **A** 源 31,585 ＝ `<詞>` 行 31,585 ＝ `caches/詞` 31,585，且逐位對齊 0 偏移（不對齊會**靜默退化成全文搜尋**）
- **B** `<聯 n=>` 2,724 種，不在 `caches/詞` 者 0（零死鏈）
- **C** 同形詞頭 592 種，`a=` 序號連續
- **D** 31,585 條逐條回讀比對內容，兩側套同一張規則 → 不符 0；詞頭逐條與源相等
- **E** 引擎檢索抽測（般若 1,162／種子 699／一即一切 9）
- **F** 版面體例：詞條必在行首、`<段/>` 不在行首／不嵌標記內／後面必接義項序號、`<>` 成對、不落跨庫鏈正文內 → 六項皆 0

### 6. 對賬：不引用產生端日誌，獨立復算

```
bun run src/audit-anchor-counts.ts      # 六項咬合
bun run src/audit-drop-reasons.ts       # 501 個丟棄按「段自身性質」重分類
bun run src/audit-lost-pages.ts         # 31 頁被吃的清單（TSV＋CSV）
```

六項：實讀行數 108,730＝庫總行數；庫內 `<聯 i=` 10,577＝打包驗收；`gate-keep` 11,077＝由 verdicts 重算；逐段重算丟棄（真重疊 500＋同起點較短 1＋退化 0）＝日誌 501；照 `wrapLine` 模擬發射 10,576＋跨標記重發 1＝庫內 10,577；`</聯>` 16,468＝開標 10,577＋5,891。
**診斷輸出本身也要自校驗**：trace 初版把 guided 與 plain 兩遍都記了，報出「基準 149、尺一拒 288」這種大於總數的數。
